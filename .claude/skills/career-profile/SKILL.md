Read these before writing anything about the user:
- profile/constraints.md — hard facts and presentation decisions. These override
  everything else. CLAUDE.md imports this file, but read it directly too: if the
  import ever fails to resolve, these constraints must still reach you.
- profile/master-resume.md — full history
- profile/achievements.md — quantified STAR stories; prefer these over resume bullets
- profile/targets.md — what they want and don't

Positioning: derive from targets.md. State it in one sentence at the top of any
draft so the user can correct it.

If a claim you want to make isn't supported by these files, stop and ask.
